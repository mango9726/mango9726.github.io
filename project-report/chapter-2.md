# บทที่ 2
## เอกสารและทฤษฎีที่เกี่ยวข้อง

การพัฒนาโครงงาน **Vocab Trainer (เว็บแอปพลิเคชันอัจฉริยะสำหรับฝึกคำศัพท์ภาษาอังกฤษด้วยเทคนิคการทบทวนเว้นระยะและเกมการศึกษา)** คณะผู้จัดทำได้ศึกษาค้นคว้าแนวคิด ทฤษฎี หลักการ และเทคโนโลยีที่เกี่ยวข้อง เพื่อนำมาเป็นกรอบแนวทางในการออกแบบและพัฒนาเว็บแอปพลิเคชันให้มีประสิทธิภาพสูงสุด โดยมีรายละเอียดตามหัวข้อดังต่อไปนี้

---

### 2.1 กรอบมาตรฐานสากล CEFR (Common European Framework of Reference for Languages)
กรอบมาตรฐานความสามารถทางภาษาของสหภาพยุโรป (CEFR) เป็นมาตรฐานสากลที่ใช้ระบุความสามารถทางภาษาของผู้เรียน โดยแบ่งออกเป็น 3 ระดับหลัก (A, B, C) และย่อยเป็น 6 ระดับ ได้แก่ A1 (Beginner), A2 (Elementary), B1 (Intermediate), B2 (Upper-Intermediate), C1 (Advanced) และ C2 (Proficient) การอ้างอิงระดับ CEFR ในโครงงานนี้ช่วยให้ผู้เรียนสามารถประเมินและเลือกเรียนคำศัพท์ที่สอดคล้องกับศักยภาพและเป้าหมายของตนเองได้อย่างแม่นยำ

### 2.2 ภาษา HTML (HyperText Markup Language)
ภาษา HTML (HyperText Markup Language) เป็นภาษามาตรฐานที่ใช้ในการสร้างและจัดโครงสร้างเนื้อหาบนเว็บเพจ โดย HTML ทำหน้าที่กำหนดองค์ประกอบพื้นฐานของเว็บไซต์ เช่น ข้อความ รูปภาพ ลิงก์ ตาราง และฟอร์มรับข้อมูล เพื่อให้โปรแกรมเบราว์เซอร์แสดงผลได้อย่างถูกต้อง

### 2.3 ภาษา CSS (Cascading Style Sheets)
ภาษา CSS (Cascading Style Sheets) เป็นภาษาที่ใช้ในการจัดรูปแบบการแสดงผลของเอกสาร HTML โดยทำหน้าที่ควบคุมรูปลักษณ์ภายนอกของเว็บเพจ เช่น สี ข้อความ ขนาด ฟอนต์ ระยะห่าง การจัดวางตำแหน่งและการรองรับการแสดงผลบนหน้าจอขนาดต่างๆ เพื่อให้เว็บไซต์มีความสวยงามและใช้งานได้ง่ายขึ้น

### 2.4 ภาษา JavaScript
ภาษา JavaScript เป็นภาษาสคริปต์ระดับสูง ที่ทำงานในลักษณะประมวลผลคำสั่งฝั่งไคลเอนต์บนเว็บเบราว์เซอร์ ทำหน้าที่เพิ่มการตอบสนองแบบไดนามิกให้กับเว็บไซต์ เช่น การตอบสนองต่อการคลิกของผู้ใช้ การตรวจสอบความถูกต้องของฟอร์มข้อมูล การดึงข้อมูลจากเซิร์ฟเวอร์โดยไม่ต้องโหลดหน้าเว็บใหม่ และการสร้างแอนิเมชัน

---

### 2.5 ทฤษฎีการลืม (Forgetting Curve) และอัลกอริทึมทบทวนเว้นระยะ (Spaced Repetition / FSRS-5)
* **เส้นโค้งการลืม (Ebbinghaus Forgetting Curve):** Hermann Ebbinghaus นักจิตวิทยาชาวเยอรมัน ได้ค้นพบว่ามนุษย์จะลืมข้อมูลที่เรียนรู้ไปอย่างรวดเร็วหากไม่มีการทบทวนซ้ำ โดยสูญเสียความจำไปมากกว่า 50% ภายใน 1 วัน และเกือบ 90% ภายใน 1 เดือน การท่องจำแบบครั้งเดียวจึงไม่เกิดความยั่งยืน
* **ระบบทบทวนเว้นระยะ (Spaced Repetition):** เป็นเทคนิคการเรียนรู้ที่ให้ผู้เรียนทบทวนข้อมูลในช่วงเวลาที่กำลังจะลืม โดยในโครงงานนี้ได้ประยุกต์ใช้อัลกอริทึม **FSRS-5 (Free Spaced Repetition Scheduler)** ซึ่งคำนวณจากค่าความมั่นคงของความจำ (Stability) และระดับความยากของคำศัพท์ (Difficulty) เพื่อกำหนดวันเวลาที่เหมาะสมที่สุดในการให้ผู้เรียนกลับมาทบทวนคำศัพท์นั้น ช่วยย้ายข้อมูลจากความจำระยะสั้นสู่ความจำระยะยาวได้อย่างมีประสิทธิภาพสูงสุด

### 2.6 หลักการออกแบบเกมเพื่อการศึกษา (Gamification & MDA Framework)
การผสานกลไกของเกม (Gamification) เข้ากับการศึกษา ช่วยลดความน่าเบื่อและสร้างแรงจูงใจในการเรียนรู้ โดยอ้างอิงตาม **MDA Framework**:
1. **Mechanics (กลไกของเกม):** ระบบการให้คะแนน XP, แถบความคืบหน้า, ระบบสะสมสตรีท (Streak), และมินิเกมฝึกทักษะ 10 รูปแบบ
2. **Dynamics (พลวัตการเล่น):** การตอบสนองของผู้เล่นต่อความท้าทาย เช่น การแข่งขันในกระดานผู้นำ (Leaderboard), ภารกิจประจำวัน (Daily Tasks), และการทบทวนคำศัพท์ที่จำยาก (Weak Words Hub)
3. **Aesthetics (สุนทรียภาพทางอารมณ์):** ความรู้สึกตื่นเต้น ท้าทาย และเพลิดเพลิน พร้อมระบบเสียงเอฟเฟกต์นุ่มนวล (Soft UI Sounds) และเครื่องเล่นเพลง Lo-Fi ที่ช่วยสร้างสมาธิขณะเรียน

### 2.7 เทคโนโลยีเว็บแอปพลิเคชันแบบก้าวหน้า (Progressive Web App - PWA) และ Service Worker
เว็บแอปพลิเคชันได้รับการพัฒนาให้ทำงานในรูปแบบ Progressive Web App (PWA) โดยใช้ **Service Worker** ในการแคชไฟล์ระบบและข้อมูลคำศัพท์ เพื่อให้ผู้เรียนสามารถใช้งานแอปพลิเคชันได้อย่างลื่นไหลแม้ในขณะออฟไลน์ (Offline Mode) และสามารถติดตั้งลงบนหน้าจอหลักของสมาร์ทโฟนหรือคอมพิวเตอร์เสมือนเป็นเนทีฟแอปพลิเคชัน

### 2.8 ระบบฐานข้อมูลคลาวด์และความปลอดภัย (Firebase & SecureStore)
ระบบจัดเก็บข้อมูลผสมผสานระหว่างการจัดเก็บในเครื่องผ่าน LocalStorage ร่วมกับระบบ **SecureStore** ที่มีการเข้ารหัสข้อมูลความปลอดภัย และรองรับการเชื่อมต่อกับ **Firebase (Authentication & Firestore)** สำหรับการซิงค์ข้อมูลผู้ใช้ข้ามอุปกรณ์แบบเรียลไทม์ ช่วยให้ผู้เรียนไม่สูญเสียข้อมูลการเรียนรู้ไม่ว่าจะใช้งานผ่านอุปกรณ์ใดก็ตาม
