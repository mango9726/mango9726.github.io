# บทที่ 2
## เอกสารและทฤษฎีที่เกี่ยวข้อง

การพัฒนาโครงงาน **Vocab Trainer (เว็บแอปพลิเคชันอัจฉริยะสำหรับฝึกคำศัพท์ภาษาอังกฤษด้วยเทคนิคการทบทวนเว้นระยะและเกมการศึกษา)** คณะผู้จัดทำได้ศึกษาค้นคว้าแนวคิด ทฤษฎี หลักการ และเทคโนโลยีที่เกี่ยวข้อง เพื่อนำมาเป็นกรอบแนวทางในการออกแบบและพัฒนาเว็บแอปพลิเคชันให้มีประสิทธิภาพสูงสุด โดยมีรายละเอียดตามหัวข้อดังต่อไปนี้

---

### 2.1 ขั้นตอนการพัฒนาซอฟต์แวร์ (Software Development Life Cycle - SDLC)
การพัฒนาซอฟต์แวร์เชิงโครงงานและนวัตกรรมการศึกษา จำเป็นต้องมีกระบวนการดำเนินงานที่เป็นระบบและตรวจสอบได้ โดยอ้างอิงตามวงจรการพัฒนาซอฟต์แวร์ (SDLC) ซึ่งประกอบด้วย 7 ขั้นตอนหลัก ดังนี้:
1. **การวางแผน (Planning):** วิเคราะห์ความเป็นไปได้ ประเมินทรัพยากร กำหนดขอบเขต และวางแผนการดำเนินงานตลอดระยะเวลาโครงงาน
2. **การวิเคราะห์ (Analysis):** ศึกษาปัญหาความต้องการของผู้ใช้งาน (User Requirements) รวบรวมข้อมูลปัญหาความจำคำศัพท์และข้อจำกัดของแอปพลิเคชันในตลาด
3. **การออกแบบ (Design):** ออกแบบสถาปัตยกรรมระบบ โครงสร้างข้อมูลคำศัพท์ (JSON/JS Modules) ส่วนติดต่อผู้ใช้ (UI/UX) ด้วยแนวคิด Modern Glassmorphism และออกแบบฐานข้อมูลในเครื่อง (LocalStorage / SecureStore)
4. **การพัฒนาระบบ (Implementation):** ลงมือเขียนโค้ดด้วย Vanilla HTML5, CSS3 และ JavaScript โดยไม่มีการใช้เฟรมเวิร์กที่ซับซ้อน เพื่อให้แอปพลิเคชันทำงานได้อย่างรวดเร็วและเบาที่สุด
5. **การทดสอบระบบ (Testing & Integration):** ทดสอบการทำงานของระบบในทุกฟังก์ชัน ทดสอบหน่วยความจำ (Unit Tests ด้วย Node.js Test Runner สำหรับ FSRS และ CSV Parser) และตรวจสอบความถูกต้องของข้อมูลคำศัพท์ทั้ง 3,600 คำ
6. **การติดตั้งใช้งาน (Deployment):** เผยแพร่เว็บแอปพลิเคชันผ่านระบบ GitHub Pages และกำหนดค่า Progressive Web Service (PWA) ให้สามารถใช้งานแบบออฟไลน์ได้
7. **การบำรุงรักษา (Maintenance):** ติดตามการใช้งานจริง รวบรวมข้อเสนอแนะจากผู้ใช้งาน และปรับปรุงแก้ไขข้อบกพร่องอย่างต่อเนื่อง

### 2.2 ทฤษฎีการลืม (Forgetting Curve) และการทบทวนเว้นระยะ (Spaced Repetition - FSRS-5)
* **เส้นโค้งการลืมของเอบบ์เฮาส์ (Ebbinghaus Forgetting Curve):** Hermann Ebbinghaus นักจิตวิทยาชาวเยอรมัน ได้ค้นพบว่ามนุษย์จะลืมข้อมูลที่เรียนรู้ไปอย่างรวดเร็วหากไม่มีการทบทวนซ้ำ โดยสูญเสียความจำไปมากกว่า 50% ภายใน 1 วัน และเกือบ 90% ภายใน 1 เดือน
* **อัลกอริทึม FSRS-5 (Free Spaced Repetition Scheduler):** ระบบได้ประยุกต์ใช้อัลกอริทึม FSRS-5 ซึ่งเป็นระบบจัดตารางทบทวนเว้นระยะที่ทันสมัยและแม่นยำที่สุด โดยคำนวณจากค่าความมั่นคงของความจำ (Stability) และระดับความยากของคำศัพท์ (Difficulty) เพื่อกำหนดวันเวลาที่เหมาะสมที่สุดในการให้ผู้เรียนกลับมาทบทวนคำศัพท์นั้นอีกครั้ง ก่อนที่สมองจะเริ่มลืม ช่วยย้ายข้อมูลจากความจำระยะสั้นสู่ความจำระยะยาวได้อย่างถาวร

### 2.3 กรอบมาตรฐานความสามารถทางภาษา (CEFR)
ระบบอ้างอิงกรอบความสามารถทางภาษาของสหภาพยุโรป (Common European Framework of Reference for Languages - CEFR) ซึ่งแบ่งระดับความสามารถออกเป็น 6 ระดับ ได้แก่ **A1, A2, B1, B2, C1 และ C2** โครงงานนี้ได้รวบรวมและจัดหมวดหมู่คำศัพท์ สำนวน (Collocations) และสำนวนโวหาร (Idioms) รวมทั้งสิ้น 3,600 คำ (ระดับละ 600 คำ / 60 วัน) เพื่อให้ผู้เรียนสามารถเลือกศึกษาได้ตรงตามระดับความสามารถและไต่ระดับได้อย่างเป็นลำดับ

### 2.4 หลักการออกแบบเกมเพื่อการศึกษา (Gamification & MDA Framework)
การผสานกลไกของเกม (Gamification) เข้ากับการศึกษา ช่วยลดความน่าเบื่อและสร้างแรงจูงใจภายใน (Intrinsic Motivation) โดยอ้างอิงตาม **MDA Framework (Mechanics, Dynamics, Aesthetics)**:
1. **Mechanics (กลไกของเกม):** ระบบการให้คะแนน XP, แถบพลังชีวิต/ความสำเร็จ, ระบบสะสมสตรีท (Streak), และมินิเกมฝึกทักษะ 10 รูปแบบ
2. **Dynamics (พลวัตการเล่น):** การตอบสนองของผู้เล่นต่อความท้าทายในเกม เช่น การแข่งขันในกระดานผู้นำ (Leaderboard), ภารกิจประจำวัน (Daily Tasks), และการทบทวนคำศัพท์ที่จำยาก (Weak Words Hub)
3. **Aesthetics (สุนทรียภาพทางอารมณ์):** ความรู้สึกตื่นเต้น ท้าทาย พึงพอใจ และความเพลิดเพลิน พร้อมระบบเสียงเอฟเฟกต์นุ่มนวล (Soft UI Sounds) และเครื่องเล่นเพลง Lo-Fi ที่ช่วยสร้างสมาธิ
