# บทที่ 3
## อุปกรณ์และวิธีการดำเนินการ

การจัดทำโครงงาน **Vocab Trainer (เว็บแอปพลิเคชันอัจฉริยะสำหรับฝึกคำศัพท์ภาษาอังกฤษด้วยเทคนิคการทบทวนเว้นระยะและเกมการศึกษา)** คณะผู้จัดทำได้กำหนดขั้นตอนการดำเนินงาน เครื่องมือที่ใช้ และวิธีการประเมินผลอย่างเป็นระบบ เพื่อให้การพัฒนาเป็นไปตามวัตถุประสงค์ที่ตั้งไว้ โดยมีรายละเอียดดังต่อไปนี้

---

### 3.1 กำหนดประชากรและกลุ่มตัวอย่าง
1. **ประชากร (Population):** นักเรียนระดับชั้นมัธยมศึกษาตอนต้นและตอนปลาย ตลอดจนผู้สนใจทั่วไปที่ต้องการพัฒนาทักษะคำศัพท์ภาษาอังกฤษ
2. **กลุ่มตัวอย่าง (Sample Group):** นักเรียนระดับชั้นมัธยมศึกษาปีที่ 2 โรงเรียนสามัคคีวิทยาคม ปีการศึกษา 2568 จำนวน 25 คน ซึ่งได้มาจากการเลือกแบบเจาะจง (Purposive Sampling)

---

### 3.2 เครื่องมือที่ใช้ในการพัฒนา
1. **ซอฟต์แวร์และภาษาคอมพิวเตอร์:**
   - **HTML5, CSS3 และ Vanilla JavaScript (ES6+):** ใช้ในการพัฒนาโครงสร้างเว็บแอปพลิเคชัน ส่วนติดต่อผู้ใช้ (UI) และตรรกะการทำงานทั้งหมด
   - **Node.js:** ใช้สำหรับรันหน่วยทดสอบ (Unit Tests) และเครื่องมือจัดการข้อมูล
   - **Firebase SDK (Authentication & Firestore):** ใช้สำหรับระบบสมาชิก (Google Sign-in, Email/Password) และการซิงค์ข้อมูลบนคลาวด์แบบเรียลไทม์
   - **Git & GitHub / GitHub Pages:** ใช้สำหรับควบคุมเวอร์ชันโค้ดและเผยแพร่เว็บแอปพลิเคชันสู่ออนไลน์
2. **ฮาร์ดแวร์:**
   - คอมพิวเตอร์โน้ตบุ๊กสำหรับพัฒนาและเขียนโค้ด
   - สมาร์ทโฟนและแท็บเล็ตสำหรับทดสอบการแสดงผลแบบ Responsive
3. **เครื่องมือประเมินผล:**
   - แบบประเมินความพึงพอใจและแบบทดสอบวัดทักษะการจำคำศัพท์ (ตามเกณฑ์มาตรฐาน Likert Scale 5 ระดับ)

### 3.4 วิธีการดำเนินงานและการพัฒนาระบบ
ระบบประกอบด้วย 8 โมดูลหลักที่พัฒนาขึ้นอย่างประณีต:
1. **Core Learning Engine:** ระบบจัดการคำศัพท์ 3,600 คำ ครอบคลุม 6 ระดับ CEFR พร้อมเสียงอ่านและตัวอย่างประโยค
2. **FSRS-5 Spaced Repetition Module (`vocab-fsrs.js`):** คำนวณรอบทบทวนคำศัพท์ตามความจำของผู้ใช้แต่ละบุคคลอย่างแม่นยำ
3. **Adaptive Placement Test (`placement.js`):** แบบทดสอบวัดระดับอัตโนมัติ 180 ข้อ เพื่อคัดกรองระดับที่เหมาะสมที่สุดให้ผู้เรียน
4. **10 Educational Gamified Modes:** มินิเกมฝึกคำศัพท์ เช่น Flashcards, Quiz, Fill-in-the-Blank, Hangman, Card Match, Cloze, Listen & Type และ Sentence Builder
5. **Pronunciation Assessment Module:** ระบบทดสอบและให้คะแนนการออกเสียงด้วยไมโครโฟนพร้อมวิเคราะห์พยางค์
6. **Learning Analytics & Weak Words Hub:** ระบบวิเคราะห์สถิติการเรียนรู้ Heatmap บันทึกสถิติความแม่นยำรายวัน และรวบรวมคำศัพท์ที่ผู้เรียนมักลืมมาทบทวนซ้ำ
7. **Spotify-Style Mini Music Player:** เครื่องเล่นเพลง Lo-Fi ในตัวเพื่อสร้างบรรยากาศผ่อนคลายและเพิ่มสมาธิ
8. **Cloud & Secure Sync System:** ระบบสำรองข้อมูลและซิงค์ข้อมูลข้ามอุปกรณ์ผ่าน Firebase / SecureStore

### 3.5 การประเมินผลและการวิเคราะห์ข้อมูล
การประเมินความพึงพอใจใช้แบบสอบถามมาตราส่วนประมาณค่า (Rating Scale) 5 ระดับ ตามเกณฑ์ของ Likert โดยกำหนดเกณฑ์การแปลความหมายค่าเฉลี่ย ดังนี้:
- **4.50 – 5.00** หมายถึง ดีมากที่สุด
- **3.50 – 4.49** หมายถึง ดี
- **2.50 – 3.49** หมายถึง ปานกลาง
- **1.50 – 2.49** หมายถึง พอใช้
- **1.00 – 1.49** หมายถึง ปรับปรุง

สถิติที่ใช้ในการวิเคราะห์ข้อมูล ได้แก่ ค่าเฉลี่ย ($\bar{x}$) และส่วนเบี่ยงเบนมาตรฐาน (Standard Deviation - S.D.) เพื่อสรุปผลการประเมินความพึงพอใจของกลุ่มตัวอย่าง
