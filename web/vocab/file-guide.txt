====================================================================
คู่มือไฟล์และโฟลเดอร์ของโปรเจกต์ Vocab Trainer
(เวอร์ชันล่าสุด — หลังตัดของสำหรับ GitHub Pages ออกแล้ว)
====================================================================

โฟลเดอร์ web/vocab/ ตอนนี้เป็น Static site ล้วน ๆ
= ใช้สำหรับ publish ขึ้น GitHub Pages โดยตรง
ไม่มี backend ไม่มีชุดทดสอบ ไม่มีรูปตัวอย่างและตัวเปิดในเครื่อง

อ่านง่าย ๆ ไม่ใช่ภาษาอังกฤษเทคนิค
- "เครื่องยนต์หลัก" = โค้ดหลักของแอป
- "ซิงก์ข้อมูล"    = เก็บบัญชี/ความคืบหน้าให้ข้ามเครื่องได้


--------------------------------------------------------------------
[1] ไฟล์ชั้นบนสุด (web/vocab/)
--------------------------------------------------------------------
- index.html      = หน้าแรกของแอป: รวมทุกหน้าจอไว้ที่นี่ (เกม, ตั้งค่า,
                    สถิติ ฯลฯ) และสั่งโหลดโค้ดทุกชิ้น เพื่อเปิดแอป
- README.md       = เอกสารวิธีใช้/วิธีเปิดแอป + วิธีติดตั้งจริง
- file-guide.txt  = ไฟล์นี้เอง ไว้อธิบายว่าไฟล์แต่ละตัวทำอะไร


--------------------------------------------------------------------
[2] โฟลเดอร์ assets/
--------------------------------------------------------------------
ทุกอย่างที่ตัวแอปต้องใช้ ตกแต่งหน้าตา + ข้อมูล + เสียง + รูป


[2.1] assets/css/  (ชุดหน้าตา)
--------------------------------------------------------------------
- style.css       = ชุดหน้าตาของแอปทั้งหมด: สี ขนาด การจัดวางทุกส่วน


[2.2] assets/js/core/  (เครื่องยนต์หลัก — โหลดก่อนตัวอื่นเสมอ)
--------------------------------------------------------------------
- app.js             = หัวใจที่สุดของแอป: เกมทุกโหมด 10+ แบบ, สถิติ,
                       ระดับ/XP, หน้าจอทั้งหมด, ระบบความคืบหน้าทั้งหมด
- i18n.js            = ข้อความภาษาไทย/อังกฤษ + ชุดไอคอนทั้งหมด
- cefr-levels.js     = บอกรายละเอียดของระดับภาษา 6 ระดับ (A1–C2)
- cefr-selector.js   = ตัวตั้งค่าระดับภาษา + คัดเลือกคำศัพท์ตามระดับ
- fsrs-scheduler.js  = ตัวคำนวณ "ควรทบทวนคำศัพท์นี้เมื่อไหร่"
                       = ระบบจำคำศัพท์ระยะยาว (FSRS-5)
- csv-tools.js       = ตัวอ่าน/เขียนไฟล์ตารางคำศัพท์ (CSV นำเข้า/ส่งออก)
- boot.js            = ตัวสตาร์ทเครื่องเล่นเพลงลอยเมื่อข้อมูลพร้อม


[2.3] assets/js/data/  (ข้อมูลคำศัพท์ทั้งหมด)
--------------------------------------------------------------------
- cefr-main.js       = คำศัพท์หลัก + ฟังก์ชันแปลภาษาไทยของทุกคำ
- levels/            = แผนเรียนรายวันของแต่ละระดับ (7 ไฟล์ = 7 ชุดแผน)
   ├ vocab-data-a1.js        … แผนคำศัพท์ระดับ A1
   ├ vocab-data-a2.js        … แผนคำศัพท์ระดับ A2
   ├ vocab-data-a1-to-a2.js  … แผนช่วงเชื่อม A1→A2
   ├ vocab-data-b1.js        … แผนคำศัพท์ระดับ B1
   ├ vocab-data-b2.js        … แผนคำศัพท์ระดับ B2
   ├ vocab-data-c1.js        … แผนคำศัพท์ระดับ C1
   └ vocab-data-c2.js        … แผนคำศัพท์ระดับ C2
- extras/            = คำศัพท์พิเศษเพิ่มเติม
   ├ vocab-extra-a1.js       … คำเสริมระดับ A1
   ├ vocab-extra-a2.js       … คำเสริมระดับ A2
   ├ vocab-extra-b1.js       … คำเสริมระดับ B1
   ├ vocab-extra-b2.js       … คำเสริมระดับ B2
   ├ vocab-extra-c1.js       … คำเสริมระดับ C1
   ├ vocab-extra-c2.js       … คำเสริมระดับ C2
   ├ vocab-extra-colloc.js   … คำผสม/สำนวน ชุดหลัก
   ├ vocab-extra-colloc-b.js … คำผสม/สำนวน ระดับ B
   ├ vocab-extra-colloc-c1.js … คำผสม/สำนวน ระดับ C1
   ├ vocab-extra-colloc-c2.js … คำผสม/สำนวน ระดับ C2
   └ vocab-th-extra.js       … คำแปลภาษาไทยของคำเสริมทั้งหมด
- examples/         = ประโยคตัวอย่างของทุกคำ
   ├ vocab-examples-a1.js … ประโยคตัวอย่างระดับ A1
   ├ vocab-examples-a2.js … ประโยคตัวอย่างระดับ A2
   ├ vocab-examples-b1.js … ประโยคตัวอย่างระดับ B1
   ├ vocab-examples-b2.js … ประโยคตัวอย่างระดับ B2
   ├ vocab-examples-c1.js … ประโยคตัวอย่างระดับ C1
   └ vocab-examples-c2.js … ประโยคตัวอย่างระดับ C2


[2.4] assets/js/games/  (เกม/แบบทดสอบแยกส่วน)
--------------------------------------------------------------------
- placement.js      = แบบทดสอบวัดระดับเริ่มต้น (แนะนำระดับภาษาให้)
- exam.js           = ข้อสอบจับเวลาเก็บคะแนน (Test Center)
- levelup-exam.js   = ข้อสอบสำหรับเลื่อนระดับเมื่อสอบผ่าน


[2.5] assets/js/ui/  (วิดเจ็ตหน้าจอ)
--------------------------------------------------------------------
- mini-player.js    = เครื่องเล่นเพลง Lo-Fi ลอยอยู่มุมจอ
                      (มีคั่นเพลงโปรด บันทึกเพลงที่ฟัง)


[2.6] assets/js/auth/  (ระบบผู้ใช้)
--------------------------------------------------------------------
- firebase-config.js = สถานที่ตั้งค่าบริการบัญชี (Email/Password + Firestore)
- auth.js            = เข้า/ออกระบบ สมัครสมาชิก ซิงก์ข้อมูลข้ามเครื่อง
- admin-panel.js     = เครื่องมือสำหรับผู้ดูแล/ทดสอบ
                       (เปลี่ยนระดับ, ตั้ง XP, เติมผลสอบ, ล้างข้อมูล)


[2.7] โฟลเดอร์เบ็ดเตล็ดใน assets/
--------------------------------------------------------------------
- audio/            = เสียงเอฟเฟกต์
   └ button sound.mp3 … เสียงกดปุ่ม
- img/              = รูปไอคอน/โลโก้ของแอป
   ├ favicon.svg            … โลโก้ติดแถบเบราว์เซอร์
   ├ icon-192.png, icon-512.png … ไอคอนแอปขนาดต่างๆ
   ├ apple-touch-icon.png   … ไอคอนติดหน้าจอ iPhone/iPad
   └ maskable-512.png       … ไอคอนปลอดพื้นที่ว่างรอบด้าน
- music/            = เพลงพื้นหลัง แบ่งเป็น 2 กลุ่ม
   ├ onpage/  … เพลงตอนอยู่หน้าปกติ (10 เพลง)
   └ ingame/  … เพลงตอนเล่นเกม (8 เพลง)


--------------------------------------------------------------------
[3] ไฟล์/โฟลเดอร์ที่ถูกตัดออกไปแล้ว (อดีต — ไม่มีแล้ว)
--------------------------------------------------------------------
- server/              = ตัวเครื่องระบบบัญชีแบบ backend (Express +
                        node_modules 626 ไฟล์ + ข้อมูลผู้ใช้) — ใช้
                        เฉพาะเปิดในเครื่อง, ไม่เกี่ยวกับ GitHub Pages,
                        ปล่อยไว้เท่ากับโชว์โค้ด+ข้อมูลสาธารณะ
- tests/               = ชุดตรวจสอบอัตโนมัติสำหรับนักพัฒนา
- screenshots/         = รูปตัวอย่างหน้าแอป (~12MB) ใช้ทำรายงาน
- start.bat            = ตัวเปิดแอปในเครื่อง Windows
- package.json         = เคยใช้สั่งรันชุดทดสอบ (ตอนนี้ไม่มีชุดทดสอบแล้ว)
- service-worker.js    = ตัวช่วยให้ใช้แบบไม่มีเน็ต (ระบบออฟไลน์)
- offline.html         = หน้าที่โผล่ตอนไม่มีเน็ต
- manifest.webmanifest = เอกสารติดตั้งแอปลงหน้าจอ (PWA)
- tools/               = สคริปต์ที่เคยใช้แค่ครั้งเดียว


--------------------------------------------------------------------
[4] วิธีเปิดแอป (ในเครื่อง / บนเว็บ)
--------------------------------------------------------------------
- บนเว็บ (GitHub Pages): เดploy โฟลเดอร์ web/vocab ทั้งหมดไปที่ Pages
- ในเครื่อง: เปิดโฟลเดอร์ web/vocab แล้วรัน
        python -m http.server 8000
  แล้วเปิด http://localhost:8000 ในเบราว์เซอร์ (Chrome/Edge แนะนำ)
- อย่าเปิด index.html โดยการดับเบิลคลิก (file://) —
  ไมโครโฟนจะขออนุญาตทุกครั้ง ควรเปิดผ่าน http:// เสมอ
